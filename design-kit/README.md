# Vitral Design Kit

Arquivos de design e tema extraídos do `testsite` para reuso em projetos estáticos semelhantes.

## Como usar
1. Copie `src/styles/vitral` para o projeto destino.
2. Importe `tokens.css`, `base.css` e `estilo.css` na página ou layout base.
3. Use `src/layouts/VitralLayout.astro` como layout base se o projeto for Astro.
4. Ajuste variáveis em `src/styles/vitral/tokens.css` para trocar marca/cores.
