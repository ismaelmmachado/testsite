# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Astro + TypeScript + CSS custom properties via `src/styles/global.css`. Deployed as a static site on GitHub Pages with GitHub Actions.

## Users

Primary users are people learning AI agents by building practical workflows. They want concise, verifiable steps rather than abstract theory and are learning by doing with human review and repetition.

## Product Purpose

Provide a minimal, clean place for practical AI agent tutorials. Each tutorial should lead to a concrete, testable result: a working setup, a script, or a repeatable workflow.

## Positioning

testsite is a concise, verifiable AI workflow tutorial site. Its differentiator is practical, reproducible outputs over broad editorial content.

## Operating Context

- Static web delivery via GitHub Pages
- Authoring directly in Astro pages and shared styles
- GitHub as both repository and publishing path
- Lightweight docs include README.md, PROJECT.md, and AGENTS.md

## Capabilities and Constraints

- No content management system; content lives in page routes
- GitHub Pages sets the publishing boundary
- Not intended as a broad productivity brand, course, or template store

## Brand Commitments

- Name: testsite
- Identity: minimal, practical, and trustworthy
- Current visual marker: simple wordmark only

2. Every tutorial ends with verification
3. Keep it minimal and reusable
